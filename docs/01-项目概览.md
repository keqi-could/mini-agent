# 项目概览

## 这是什么

mini-agent 是一个用纯 Python 从零实现的轻量级 Agent 应用。它不依赖 LangChain、LlamaIndex 等任何 Agent 框架，核心的 ReAct 循环、工具调用协议、向量检索全部手写，代码总量控制在几百行以内，方便逐行读懂。

项目定位是「可讲清楚的工程样本」：每一层职责单一，能解释清楚为什么这样设计，而不是把框架黑盒包一层。

## 核心能力

- ReAct 循环：模型自主决定「思考 → 行动 → 观察 → 再思考」，直到收敛出答案
- 工具调用：通过 JSON Schema 注册工具，模型返回 tool_calls，本地执行后回填结果
- RAG 检索：文档切块后向量化，手写余弦相似度做 top-k 召回
- 防幻觉约束：system prompt 要求回答必须基于检索内容，资料不足时明确说不知道
- 多轮记忆：同一个 Agent 实例保留上下文，支持连续追问
- 上下文压缩：超出轮次上限的老对话自动压成摘要，成本不随轮次线性增长
- 可观测：每一轮对话的工具调用轨迹可折叠查看，知识库状态在界面上可见

## 技术栈

运行环境是 Python 3.13。对话模型使用 DeepSeek 的 deepseek-chat，通过 OpenAI 兼容接口调用；向量模型使用智谱的 embedding-3，输出 2048 维向量。界面用 Streamlit，部署在 Streamlit Cloud。依赖清单里只有 openai、python-dotenv、numpy、streamlit 四个包。

## 目录结构

app.py 只负责界面渲染与交互；agent.py 是 Agent 类，包含 ReAct 循环、多轮记忆与轨迹收集；tools.py 是工具注册表，函数本体与 JSON Schema 定义在一起；knowledge.py 负责文档加载、切块、向量化与检索；docs 目录存放知识库原始文档。

agent_loop.py、tool_call.py、rag_demo.py、hello_agent.py 是分阶段的教学示例，保留下来用于对照学习。
